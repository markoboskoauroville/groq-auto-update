# capi (Claude Code on the API credit, the CAPI tab)

Marko, 17.11.2026: "can queen be used as capi ... add capi tab to queen software so i can have nicer ui". `capi` (command in
~/.local/bin) is a chat with Claude Code that runs headless `claude -p` on his $100 promotional API credit (that credit pays only
headless runs, not a normal Claude Code window). CAPI is Queen's first top-level workspace, beside AUTO UPDATE:
Markdown answers, one line per tool, cost per answer, "API ($NN.NN left)" at the top, model picker (HAIKU, SONNET default,
OPUS, FABLE), folder picker (default ~/Developer/claude-code), Stop, chats (one Claude Code session each, so the chat continues).

When you send a task there: Marko asks for real work in a project folder (edit files, run commands, review code) that needs Claude
Code's hands and is not a question for you or for the TRIPLE room. Cheapest model first: haiku for small things, sonnet to code,
opus for hard debugging; fable only with a reason. Every run costs real credit: say the model and the folder before you start.

How you start a run (one call, answer comes back whole):
`POST /api/capi/ask {"text": "<the task>", "cwd": "/Users/markobosko/Developer/<project>", "model": "claude-haiku-5-5", "id": "<room id to continue, optional>"}`
-> `{answer, cost, id, left, error}`. Keep the `id` to continue the same chat. The streaming form for the window is
`POST /api/capi/turn {id, text}` (NDJSON). Other routes: `GET /api/capi/credit`, `/folders`, `/list`, `/get?id=`, `POST /new`, `/settings`, `/stop`, `/delete`.

ONE credit number: every run (capi, claude-api-mode, the tab) is a line in ~/.cache/claude-api-ledger.jsonl; the balance is
`tools/api_credit.py` (calibrated $96.66 at 17.11.2026 13:50 minus later spend). Never quote another number. Credit expires 15.12.2026.
Traps: the key is never printed; the run's folder must be inside the home folder; Stop kills the run, the cost so far is still booked.

v26 (18.11.2026), MASTER / SLAVE. Marko: "next to each provider ... a switch master or slave" and "if Anthropic is master, he decides which of Google's models to use". Beside every PROVIDER radio there is a small switch OFF / MASTER / SLAVE (click cycles). With one master and one slave (different providers, both keyed) the header shows "PAIR | <MASTER> → <SLAVE>" with ROUNDS n (click: one more, 1 to 10) and CAP $x (click: set); a prompt then goes to the master, who plans, the slave works in the chat's folder and reports, the master reviews (VERDICT: DONE or FIX) and picks the slave's model for each round (SLAVE_MODEL line). Each message in the chat is labelled e.g. "ANTHROPIC · MASTER → GOOGLE CLOUD · SLAVE (PLAN · slave gemini-3.5-flash-lite: reason)"; the turn ends with one PAIR line (how it ended, master cost, slave cost, total of the cap). With no master or no slave the radio's provider works alone, exactly as v25. Routes: `GET/POST /api/capi/pair`, `POST /api/capi/ask` with `master`/`slave` (and `gmodel`, `cap_usd`, `max_rounds`) for a pair run; STOP (`/api/capi/stop`) stops both sides. The input row says MASTER MODEL in a pair (the master's own model; the slave's model is the master's choice). Full skill: master-slave.md.

v29: the top-level status line now has only CAPI (first) and AUTO UPDATE (last); the old TRIPLE / CHATS / NEW CHAT controls are removed from that line, while CAPI's own chat list and NEW CHAT remain. The AUTO UPDATE view calls the existing `/api/auto_update/*` API, polls job progress, and asks before running the pipeline; API use also needs explicit consent if the backend requests it. That pipeline's allowlist is backend-only (`qwen_app/app.py`, `qwen_app/index.html`, `qwen_app/auto_updater.py`); Swift source still uses the GitHub mac-app release workflow.

The CAPI ROUTER switch is per chat and off by default. It spends one judge call on the selected provider's cheapest catalog model, routes to a suitable model, and records the model, reason, and router cost in the chat. It cannot run with PAIR mode. A routing failure is an error, not a silent fallback. Google Cloud credit is a labeled estimate from a historical Billing snapshot and token-price ledger, never a live balance.

Python clients: `tools/queen_capi.py`; see `CAPI_PYTHON_API.md` and `GET /api/capi/capabilities`. The folder picker accepts existing folders below the home directory only. Gemini tool calls receive attachments in the selected folder and use folder-confined tools. Supported Gemini audio/video MIME types are advertised by the capabilities endpoint and documented in `CAPI_PYTHON_API.md`; other providers and PAIR mode reject media they cannot use.
